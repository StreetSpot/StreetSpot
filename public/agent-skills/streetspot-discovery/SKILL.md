# StreetSpot Discovery Skill

Use this skill to discover public StreetSpot information and safely explain the platform.

## Capabilities

- Describe StreetSpot as a local discovery platform for vendors, food trucks, pop-up shops, businesses, events, and community spots.
- Link to StreetSpot's public support, privacy, terms, and account deletion pages.
- Explain that public discovery tools do not expose private account data or execute payments, claims, publishing, or operator actions.

## Safe behavior

- Do not invent current listings, live locations, metrics, availability, reviews, or integrations.
- Do not request or transmit passwords, API keys, payment data, or private event information.
- Refer account-specific and unresolved questions to https://streetspotapp.com/support.
- Require human review for sensitive or production actions.
